## 明确不做（V1.0）

| 项 | 原因 |
|---|---|
| 旧版存档 / 键位迁移 | 规划 §1.3 明确不做 |
| 无授权的商业 JAR | 规划 §1.3。注意这与「内置游戏」是两回事：随包的 104 款均为自研或 MIT（`SOURCE_AUDIT.md` §4.2），**可以内置**；此条约束的是新增来源，不收录任何缺授权的商业作品 |
| 联网类 MIDlet（socket / HTTP 出网） | 旧版依赖第三方私有通道，新版不重建；V1.0 按不支持处理并在 UI 说明 |
| 3D（JSR-184 / Mascot Capsule / JSR-239） | 自建内核不含相关类；是否补回取决于 `CORE_EVALUATION.md` §6 B1 |
| 蓝牙 / OBEX / 无线消息 | 同上 |
| 云存档 / 账号 | 规划 §1.2，仅在产品明确要求且合规方案就绪时做 |

## 能力降级的产品表达

自建内核缺 270 个类，这必须在产品里**显式表达**，而不是让用户在运行到一半时撞墙：

1. 导入阶段读 MIDlet 清单，识别所需 JSR（`MicroEdition-Profile`、`MIDlet-1` 之外的可选包声明不足时，退化为运行时探测）。
2. 命中不支持能力时，在启动前给出「该程序需要 3D / 蓝牙支持，当前版本不可用」，而非黑屏。
3. 兼容性说明页列出已知限制，并允许用户查看自己设备的实测记录。

实现方式待 F4 完成后细化（见 ADR 0002 的「能力门禁」一节）。
